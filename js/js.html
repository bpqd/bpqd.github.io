WebXR

WebXR is an open web standard (the WebXR Device API) that lets virtual reality (VR) and augmented reality (AR) experiences run directly inside a web browser. Instead of downloading an app from a store, you simply click a link or scan a QR code to enter an immersive 3D space

Three.js

Library and application programming interface used to create and display animated 3D computer graphics in a web browser using WebGL
