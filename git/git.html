Git

Quick links: GitHub GitHub Pages

Git — это распределённая система контроля версий, созданная Линусом Торвальдсом в 2005 году для отслеживания изменений в исходном коде. Она работает как «машина времени» для проектов и сохраняет историю разработки в виде контрольных точек (коммитов). Благодаря этому разработчик может в любой момент посмотреть, кто и какие правки внёс, или безопасно откатить проект к предыдущей рабочей версии

Главное преимущество Git заключается в удобной организации параллельной и командной работы над одним проектом. Система позволяет создавать независимые ветки для разработки новых функций или исправления ошибок. Когда новая часть кода готова и проверена, её можно объединить с основным проектом, а при одновременном редактировании одного файла разными людьми программа поможет найти и разрешить конфликты

Важно не путать сам Git с такими облачными платформами, как GitHub или GitLab. Git — это консольная утилита, которая устанавливается локально на компьютер и позволяет работать с историей файлов даже без интернета. Онлайн-сервисы же выступают в роли удалённых серверов-хранилищ, куда программисты загружают свои репозитории для резервного копирования и удобного обмена кодом с коллегами

GitHub

GitHub — это крупнейший веб-сервис и облачная платформа для хостинга IT-проектов и совместной разработки на базе системы контроля версий Git.
